# Security policy

## Supported versions

Only the latest release gets fixes. Installed copies offer each update, so please check that the
problem still happens on the newest version from https://tmplayer.org/download/ before reporting.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately instead:

- through GitHub: the **Report a vulnerability** button on the
  [Security tab](https://github.com/dracu-lah/TMPlayer/security/advisories/new), or
- by email to hello@tmplayer.org.

Include the platform, the app version, what an attacker could do, and the steps to reproduce it.
You will get a reply within a week. Once a fix is released, the report can be credited to you if
you like.

## Scope

TMPlayer has no server of its own: it talks to Telegram through TDLib and keeps everything on your
device. Problems in Telegram itself or in TDLib belong upstream, though a heads up is welcome when
TMPlayer is affected.
