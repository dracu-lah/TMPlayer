      Before you open the file
      
          
      Three things worth knowing about a sideloaded APK, this one included.
      
        
      
      
      

      
      
        
      
          
      
            
              
            
            What you are getting
          
      
          
        
            
      • Android 8.0 and above, on a television, a stick, a box or a phone. It has been run in anger on a Mi TV Stick with 1 GB of RAM.
        • 
            
      • The universal build. Older releases were split by chip type and those files are still on GitHub; anything current is the one file.
        • 
            
      • The source of that exact build. Every release carries a source archive and the R8 mapping file, so a crash report from it can be decoded and the binary can be checked against the code.
        • 
          
      
        
      
        
      
          
      
            
              
            
            What it will not do
          
      
          
        
            
      • It is not on the Play Store, so Android will ask you to allow this one install. That prompt is doing its job: read it.
        • 
            
      • It does not come with media. It shows you what is already in your own chats and nothing else.
        • 
            
      • It will not update through the store either. The app checks GitHub itself and offers you the newer release when there is one.
        •
