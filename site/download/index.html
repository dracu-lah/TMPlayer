Windows

Windows 10 and 11, 64-bit

Your computer

  • Installer Start here

    Adds a Start menu entry and a desktop shortcut. No administrator needed.

    TMPlayer-<version>-windows-x64.msi

    Download

Windows will warn you first. The build is not signed yet, so SmartScreen says Windows protected your PC. Click More info, then Run anyway.

Linux

x86_64, with glibc 2.38 or newer: Ubuntu 24.04, Debian 13, Fedora 39 and later

Your computer

  • AppImage Any distribution

    One file that runs on any distribution. Make it executable and open it.

    chmod +x TMPlayer-<version>-x86_64.AppImage
    Download

  • Arch Linux

    A PKGBUILD lives in desktop/packaging/aur. It builds from the linux-x64.tar.gz on each release. The AppImage also runs on Arch.

    The recipe

How to install on Linux, and put it in the app menu

macOS later. A Mac build will follow once it can be signed. There is no iPhone or iPad version.

Each release also carries SHA256SUMS-<version>.txt. Check a download against it with sha256sum -c --ignore-missing in the same folder.

    Before you open the file
    
          
    Worth knowing about any app from outside the store.
    
        
    
      
    

      
    
        
    
          
    
            
              
            
            What you are getting
          
    
          
      
            
    • Android 8.0 and above on a TV, stick, box or phone. Tested on a 1 GB Mi TV Stick.
      • 
            
    • A desktop app for Windows and Linux, with the same library and sign-in, played through mpv.
      • 
            
    • The source of that exact build. Every release links the source tree it was built from, with GitHub's source archives.
      • 
          
    
        
    
        
    
          
    
            
              
            
            What it will not do
          
    
          
      
            
    • It is not in a store, so Android asks to allow the install and Windows shows SmartScreen. Read those prompts.
      • 
            
    • It comes with no media. It only shows what is already in your chats.
      • 
            
    • No store updates. TMPlayer looks for a new version itself and offers it in the side bar instead; the Windows installer and the AppImage update in place from there.
      •
