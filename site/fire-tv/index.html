Install TMPlayer on Fire TV

Fire TV Sticks, the Fire TV Cube and Fire TV Edition televisions run Android underneath, so the same APK installs on them. It takes about ten minutes, once.

Show me the steps Other devices

Will it run on yours?

TMPlayer needs Android 8.0 or above. On a Fire TV that means Fire OS 7 or newer, which is listed under Settings, My Fire TV, About.

Yes

  • Fire TV Stick, Stick 4K and 4K Max, Fire TV Cube, and Fire TV Edition and Omni televisions, on Fire OS 7 or 8.
  • The one universal APK, the same file as every other Android TV.
  • The TV layout, the remote and QR sign-in, exactly as on Android TV.

No

  • Fire OS 6 and older. They are built on Android 7.1, below the minimum, and say the package cannot be installed.
  • Fire TV models that run Vega OS. They are not Android underneath and cannot install an APK.

Five steps with the remote

No computer needed. Amazon's store does not carry TMPlayer, so the free Downloader app fetches it instead.

  1. Turn on Developer options

    Open Settings, My Fire TV, About, and press OK on the device's name (for example Fire TV Stick) seven times, until it says you are now a developer.

    If Developer options is already listed under My Fire TV, skip this step.

  2. Install Downloader

    Go to Find, then Search, type Downloader and pick the orange app by AFTVnews. Press Get or Download. It is free.

  3. Let Downloader install apps

    Back in Settings, My Fire TV, Developer options, open Install unknown apps and turn it on for Downloader. On some older versions the switch is called Apps from Unknown Sources.

  4. Fetch the APK

    Open Downloader, allow it access to files if it asks, and type this into its address box:

    tmplayer.org/download

    The download page opens inside Downloader. Choose the Android TV download, the file ending in -universal.apk, then press Install when Fire OS asks. Downloader offers to delete the APK afterwards: say yes, it is no longer needed.

    A short Downloader code is coming, so you will be able to type a few digits instead of the address.

  5. Open it and sign in

    TMPlayer lands under Your Apps, the icon of three squares and a plus on the home screen. To keep it at the front, highlight it, press the menu button (three lines) and choose Move.

    Open it and scan the QR code: in Telegram on your phone, Settings, Devices, Link Desktop Device.

Or with a computer or a phone

Both still need Developer options from step 1.

adb from a computer

Turn on ADB debugging in Developer options, and find the Fire TV's IP address under Settings, My Fire TV, About, Network. Then, on the same network, with the APK from the download page:

adb connect <fire-tv-ip>:5555
adb install TMPlayer-<version>-universal.apk

Accept the debugging prompt that appears on the television the first time.

Send files to TV

Install Send files to TV on your phone and on the Fire TV, download the APK on the phone and send it across. Turn on Install unknown apps for Send files to TV, as in step 3, then open the file on the television.

The remote, and keeping it up to date

Everything works from the Fire TV remote that came in the box.

The D-pad does it all

Arrows to move, OK to play, Back to go back. The rail, the grids and the player are all built for it. More on the TV layout.

Voice search, where Fire OS allows

TMPlayer's own search can listen through the system's speech recognition. Whether that works depends on the Fire OS version; typing always does.

Updates come to you

TMPlayer checks for new versions itself and offers them. The first time, Fire OS asks you to let TMPlayer install apps, the same switch as step 3.

If it goes wrong

There is no Install unknown apps switch

Developer options is still hidden. Go back to step 1 and press the device's name seven times. Install Downloader first, too: the switch only lists apps that are already installed.

It says there was a problem parsing the package, or the app was not installed

Usually the Fire OS version is older than 7, the download did not finish, or there is too little free space. If an older TMPlayer from somewhere else is installed, uninstall it first. The adb route above prints the real reason.

I cannot find TMPlayer after installing it

Apps installed from outside the store go to the end of Your Apps. It is also under Settings, Applications, Manage Installed Applications.

Still stuck? Open an issue with your Fire TV model, its Fire OS version and what the screen said.
