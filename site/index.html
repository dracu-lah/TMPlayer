Set up in three steps

You do it once. Then it works like any other TV app.

  1. Get the file

    One universal APK for every Android TV and phone, plus a Windows installer and Linux packages.

    Go to the download page

  2. Install it

    On a phone, open the file. On a TV, use a free helper app or adb. On a computer, it installs like any app.

    Read the install steps

  3. Scan the QR code

    Sign in with Telegram's own Link Desktop Device flow. No bot, no server, nothing in between.
