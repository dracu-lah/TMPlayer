Every release

What changed in each TMPlayer release, newest first. Installed copies offer each update, so this is where to find out what it brings.

Download the latest Follow by RSS

TMPlayer 1.24.0

6 October 2026·On GitHub

TMPlayer now speaks 21 languages (machine translated for now, corrections welcome on GitHub). Home has rows, series get their own page, and search covers all your chats. Optional posters and overviews come from TMDB, TVmaze and AniList, and subtitles can be found online through OpenSubtitles. The player adds volume boost, a sleep timer, a "still watching?" check, subtitle and audio delay, subtitle size and position, and simpler controls on phone, TV and desktop. Downloads can be removed after watching. On TV: Fire TV remotes, Watch Next and seek previews. On desktop the QR sign in works in release builds, and there is a new About screen everywhere.

TMPlayer 1.22.1

5 October 2026·On GitHub

Videos play on Android TV again. In 1.22.0 the player closed itself a few seconds into every video on a television; phones and computers were not affected.

TMPlayer 1.22.0

4 October 2026·On GitHub

Smaller downloads. The Android APK is about half its old size, and the Windows and Linux packages are a third to almost two thirds smaller. The Linux tarball is now a .tar.xz.

TMPlayer 1.21.0

4 October 2026·On GitHub

Finished episodes now get a tick, and any video can be marked as watched or unwatched by hand. A new Watched tab lists what you have finished. Searching a chat now finds videos outside the size limits, and the grid says how many videos the limits are hiding. On a TV, the release page opens as a QR code. On Windows, the media keys and the media flyout control the player.

TMPlayer 1.20.0

4 October 2026·On GitHub

The first release with a desktop app for Windows and Linux. It signs in with the same Telegram account and plays the same chats, with the keyboard, the mouse and your media keys.

TMPlayer 1.16.0

29 August 2026·On GitHub

No notes were written for this release. The release on GitHub lists its files.

Releases from before 1.16.0 are on GitHub as tags. Every release links the source tree it was built from.
