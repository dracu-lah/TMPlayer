How to install it, wherever you watch

On a TV, a phone, Windows or Linux. You only do it once.

Get the file first The full INSTALL.md
Android TV and phone Windows Linux Desktop and menu shortcuts

On Android TV or a phone: four steps

This is how any app from outside the store gets onto an Android device.

  1. Allow apps from outside the store

    On a TV: Settings, Device Preferences, About, then press Build seven times. Turn on Unknown sources for the app that copies the file.

    On a phone: nothing yet. Android asks when you first open the file.

  2. Get the file onto the device

    On a phone, download the APK and open it. On a TV, use the free Downloader or Send files to TV, apps, or adb on the same wifi:

    adb connect <tv-ip>:5555
adb install TMPlayer-<version>-universal.apk

    Turn on network debugging in Developer options first.

    On a Fire TV the menus are named differently: follow the Fire TV guide.

  3. Sign in

    On a TV, scan the QR code: in Telegram on your phone, open Settings, Devices, Link Desktop Device.

    On a phone, enter your number instead. The QR code still works for an account on another phone.

  4. Pick a chat and press play

    Your chats open as grids of playable videos. Pick one and it starts in seconds.

INSTALL.md has every step in full, plus controls and troubleshooting.

On Windows

Windows 10 or 11, 64-bit. No administrator password needed.

  1. Download the installer

    Take TMPlayer-<version>-windows-x64.msi from the download page. The portable zip is no longer published: if you used it, delete its folder and install the MSI. Your sign-in and settings live in your user profile, not in that folder, so they carry over.

  2. Get past SmartScreen

    The build is not signed yet, so Windows says Windows protected your PC. Click More info, then Run anyway.

  3. Install and open it

    Click through the installer. TMPlayer lands in the Start menu and on the desktop. A newer MSI upgrades it in place.

  4. Sign in with the QR code

    Scan the QR code with Telegram on your phone: Settings, Devices, Link Desktop Device. Or choose Log in by phone number.

On Linux

64-bit x86, with glibc 2.38 or newer: Ubuntu 24.04, Debian 13, Fedora 39 and later. Then sign in with the QR code.

AppImage, on any distribution

chmod +x TMPlayer-<version>-x86_64.AppImage
./TMPlayer-<version>-x86_64.AppImage

Or tick Allow executing file as program in the file's properties and double click it.

Arch Linux

Build the package from the recipe in desktop/packaging/aur with makepkg -si, or use the AppImage.

Moving from the deb, rpm or Flatpak

These are no longer published. Remove the old one (sudo apt remove tmplayer, sudo dnf remove tmplayer or flatpak uninstall io.github.dracu_lah.TMPlayer) and take the AppImage. After the deb or rpm, your sign-in and settings carry over. The Flatpak kept them inside its sandbox, so copy them out first or sign in again.

The Arch package adds a menu entry for you. For the AppImage, see below.

On the desktop, in the menu, on the taskbar

How to keep it one click away.

Windows

MSI install: it is already in Start and on the desktop. To pin it, right click it in Start and choose Pin to taskbar.

Linux: the Arch package

It is in the app menu as soon as it installs, under Multimedia or Sound and Video.

GNOME: right click it in Activities, Pin to Dash. KDE Plasma: right click it in the launcher, Pin to Task Manager.

Linux: AppImage, in the app menu

A single file has no menu entry, so make one. These commands move the AppImage into place, fetch the icon and write a launcher:

mkdir -p ~/Applications ~/.local/share/icons ~/.local/share/applications
mv ~/Downloads/TMPlayer-<version>-x86_64.AppImage ~/Applications/TMPlayer.AppImage
chmod +x ~/Applications/TMPlayer.AppImage
curl -Lo ~/.local/share/icons/tmplayer.png https://tmplayer.org/icon-512.png

cat > ~/.local/share/applications/tmplayer.desktop <<EOF
[Desktop Entry]
Type=Application
Name=TMPlayer
Comment=Telegram media player
Exec=$HOME/Applications/TMPlayer.AppImage
Icon=$HOME/.local/share/icons/tmplayer.png
Categories=AudioVideo;Video;Player;
Terminal=false
StartupWMClass=com-tmplayer-desktop-MainKt
EOF

chmod +x ~/.local/share/applications/tmplayer.desktop
update-desktop-database ~/.local/share/applications

Then pin it as above.

Prefer clicking? Gear Lever and AppImageLauncher do all this for you.

Linux: an icon on the desktop

Copy the launcher made above to the desktop and mark it trusted:

cp ~/.local/share/applications/tmplayer.desktop ~/Desktop/
chmod +x ~/Desktop/tmplayer.desktop
gio set ~/Desktop/tmplayer.desktop metadata::trusted true

For the Arch package, copy its launcher instead: /usr/share/applications/io.github.dracu_lah.TMPlayer.desktop.

GNOME needs the Desktop Icons NG extension and a one-time Allow Launching. KDE Plasma asks once; Xfce and Cinnamon read the trusted flag.

If it goes wrong

The fixes for nearly every stuck install.

The television says the app is blocked or the install button does nothing

Unknown sources is set per app. Turn it on for Downloader or Send files to TV, not TMPlayer, then open the file again.

adb connect refuses the connection

Turn on network debugging, use the same network on both, and accept the trust prompt on the TV screen.

The QR code will not scan from across the room

Stand closer and hold the phone square to the screen. Scan from Telegram's Settings, Devices, Link Desktop Device, not the camera app.

Windows shows no Run anyway button

Click More info first. A work computer may block unsigned apps by policy.

The AppImage does nothing when opened

Usually FUSE is missing. Install libfuse2t64 (Ubuntu 24.04 and newer) or libfuse2 (22.04), or skip FUSE with ./TMPlayer-<version>-x86_64.AppImage --appimage-extract-and-run.

The window is blank or grey on a tiling window manager

On sway, i3, Hyprland and similar, start it with _JAVA_AWT_WM_NONREPARENTING=1 set.

Still stuck? Open an issue with your device, its version and what the screen said.
