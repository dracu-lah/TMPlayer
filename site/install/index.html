How to install it, wherever you watch

On a television, a phone, a Windows computer or a Linux one. You only do it once, and signing in is the only step that needs your phone in your hand.

Get the file first The full INSTALL.md

On Android TV or a phone: four steps

Nothing here is specific to TMPlayer: it is how any app that is not in the store gets onto an Android device.

  1. Allow apps from outside the store

    On a television: Settings then Device Preferences then About, and press Build seven times. Now turn on Unknown sources for whichever app you use to copy the file over.

    On a phone: nothing to do yet. Android asks you the first time you open the file, and you say yes then.

  2. Get the file onto the device

    On a phone, download the APK and open the file when it lands. On a television it is easiest with a free app from the Play Store, such as Downloader or Send files to TV, pointed at the same link. With a computer on the same wifi, adb works too:

    adb connect <tv-ip>:5555
adb install TMPlayer-<version>-universal.apk

    For that one, turn on network debugging in Developer options first.

  3. Sign in

    On a television it shows a QR code: open Telegram on your phone, go to Settings, then Devices, then Link Desktop Device, and point the camera at the screen. Nothing to type with the remote.

    On a phone it asks for your number instead, with the country picker and the code boxes Telegram itself uses. The QR route is still there, for an account that lives on another handset.

  4. Pick a chat and press play

    Your chats open into grids or rows of their playable videos: big cards and a focus ring on a television, dense tiles under your thumb on a phone. Choose one and it starts in a few seconds.

INSTALL.md covers every step in full, plus the remote, the touch and the keyboard references and troubleshooting.

On Windows

Windows 10 or 11, 64-bit. The installer puts it in your own user folder, so it needs no administrator password.

  1. Download the installer

    Take TMPlayer-<version>-windows-x64.msi from the download page. If you would rather install nothing at all, take the portable zip instead, unzip it anywhere and run TMPlayer.exe from the folder.

  2. Get past SmartScreen

    The build is not signed yet, so Windows says Windows protected your PC. Click More info, then Run anyway. The same warning can appear the first time you open the portable TMPlayer.exe.

  3. Install and open it

    Click through the installer. TMPlayer is then in the Start menu, with a shortcut on the desktop. Installing a newer MSI later upgrades it in place and keeps you signed in.

  4. Sign in with the QR code

    A QR code fills the window. On your phone open Telegram, then Settings, Devices, Link Desktop Device, and point the camera at the screen. Log in by phone number is underneath it, for an account with no phone to hand.

On Linux

64-bit x86 for now. Every format below is the same app, so pick by how you like to install things, then sign in with the QR code exactly as on Windows.

Debian, Ubuntu, Mint and relatives

sudo apt install ./tmplayer_<version>_amd64.deb

Fedora, RHEL and rebuilds

sudo dnf install ./tmplayer-<version>.x86_64.rpm

openSUSE: sudo zypper install ./tmplayer-<version>.x86_64.rpm

Flatpak, on any distribution

flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./TMPlayer-<version>.flatpak

The first line adds Flathub, where the org.freedesktop.Platform runtime comes from, and does nothing if you already have it.

AppImage, on any distribution

chmod +x TMPlayer-<version>-x86_64.AppImage
./TMPlayer-<version>-x86_64.AppImage

Or tick Allow executing file as program in the file's properties and double click it.

Tarball, on any distribution

mkdir -p ~/.local/opt
tar xzf TMPlayer-<version>-linux-x64.tar.gz -C ~/.local/opt
~/.local/opt/TMPlayer/bin/TMPlayer

Arch Linux

Build the package from the recipe in packaging/aur with makepkg -si, or use the AppImage or the Flatpak, which run on Arch as they are.

The deb, rpm and Flatpak add TMPlayer to your app menu on their own. The AppImage and the tarball do not, which is what the next section is for.

On the desktop, in the menu, on the taskbar

Where to find it once it is installed, and how to keep it one click away.

Windows

Installed with the MSI: it is already in the Start menu and on the desktop. To pin it to the taskbar, open Start, find TMPlayer, right click it and choose Pin to taskbar. Or, while it is running, right click its taskbar icon and choose the same.

From the portable zip: right click TMPlayer.exe, then Send to, then Desktop (create shortcut). On Windows 11 those entries are under Show more options. For a Start menu entry, press Win+R, type shell:programs and move that shortcut into the folder that opens.

Linux: deb, rpm and Flatpak

TMPlayer is in the app menu as soon as the install finishes, under Multimedia or Sound and Video.

GNOME: open Activities, search for TMPlayer, right click it and choose Pin to Dash (Add to Favourites on older releases). KDE Plasma: open the application launcher, right click TMPlayer and choose Pin to Task Manager or Add to Favourites. Either way, right clicking the icon of the running app does the same.

Linux: AppImage and tarball, in the app menu

A single file has nowhere to put a menu entry, so you make one. Move the app somewhere it will stay, fetch the icon, and write a launcher file. These commands do it for the AppImage, renamed so an update is a drop-in replacement:

mkdir -p ~/Applications ~/.local/share/icons ~/.local/share/applications
mv ~/Downloads/TMPlayer-<version>-x86_64.AppImage ~/Applications/TMPlayer.AppImage
chmod +x ~/Applications/TMPlayer.AppImage
curl -Lo ~/.local/share/icons/tmplayer.png https://tmplayer.org/icon-512.png

cat > ~/.local/share/applications/tmplayer.desktop <<EOF
[Desktop Entry]
Type=Application
Name=TMPlayer
Comment=Telegram media player
Exec=$HOME/Applications/TMPlayer.AppImage
Icon=$HOME/.local/share/icons/tmplayer.png
Categories=AudioVideo;Video;Player;
Terminal=false
EOF

chmod +x ~/.local/share/applications/tmplayer.desktop
update-desktop-database ~/.local/share/applications

The shell fills in $HOME as it writes the file, because a launcher needs full paths and does not understand ~. For the tarball unpacked into ~/.local/opt, the one line that changes is Exec=$HOME/.local/opt/TMPlayer/bin/TMPlayer. Then pin it to the dock or the task manager as above.

Would rather click than type? Gear Lever and AppImageLauncher both move an AppImage into place and make its menu entry for you.

Linux: an icon on the desktop

Copy the launcher onto the desktop and tell the desktop you trust it. For the AppImage or tarball launcher made above:

cp ~/.local/share/applications/tmplayer.desktop ~/Desktop/
chmod +x ~/Desktop/tmplayer.desktop
gio set ~/Desktop/tmplayer.desktop metadata::trusted true

For a deb, rpm or Flatpak install, find the launcher it added and copy that one instead:

find /usr/share/applications ~/.local/share/flatpak/exports/share/applications \
  /var/lib/flatpak/exports/share/applications -iname '*tmplayer*.desktop' 2>/dev/null

On GNOME the desktop shows icons only with the Desktop Icons NG extension, and the first time you need to right click the icon and choose Allow Launching. KDE Plasma asks once whether to run it; Xfce and Cinnamon read the trusted flag the last command set.

If it goes wrong

The ones that account for nearly every stuck install, on a television and on a computer.

The television says the app is blocked or the install button does nothing

Unknown sources is granted per app, not once for the device. Turn it on for the app that is holding the file, which is Downloader or Send files to TV rather than TMPlayer itself, then open the file again.

adb connect refuses the connection

Network debugging has to be on in Developer options, the two devices have to be on the same network, and the television will show a prompt asking whether to trust the computer. That prompt only appears on the screen, so look up before assuming it failed.

The QR code will not scan from across the room

Stand closer than feels necessary and hold the phone square to the screen. The code refreshes on its own every so often, so a stale one is never the problem for long. Telegram's scanner lives under Settings, Devices, Link Desktop Device, not in the camera app.

Windows shows no Run anyway button

Click More info first: the button only appears after it. On a work computer, a policy set by whoever manages it can forbid unsigned apps outright, and nothing in the app can change that. For the portable zip, right click the zip, choose Properties, tick Unblock and unzip it again, so Windows stops asking about every file inside.

The AppImage does nothing when opened

Most often FUSE is missing, which Ubuntu 22.04 and newer no longer install by default. Run it from a terminal to see the message, then install libfuse2t64 (Ubuntu 24.04 and newer) or libfuse2 (22.04). Or skip FUSE entirely with ./TMPlayer-<version>-x86_64.AppImage --appimage-extract-and-run.

Flatpak says a runtime is missing

The bundle takes its org.freedesktop.Platform runtime from Flathub. Add the remote with flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo and run the install again.

The window is blank or grey on a tiling window manager

Java needs telling that the window manager does not reparent. Start it with _JAVA_AWT_WM_NONREPARENTING=1 set, on sway, i3, Hyprland and the like.

Still stuck? Open an issue with the device or the system, its version and what the screen said.
